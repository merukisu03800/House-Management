## シミュレーション

```bash
python3 sim/loan_simulator.py                # sim/params.json の設定で試算
python3 sim/loan_simulator.py --price 5500   # 物件価格(万円)だけ変えて試算
python3 sim/loan_simulator.py --down 0.2     # 頭金を価格の20%にして試算
python3 sim/loan_simulator.py --savings 300  # 今の貯金(万円)を差し引いて積立額を逆算
```

出力される内容:
1. 購入時に必要な現金（頭金＋諸費用＋生活防衛資金）と、頭金の比率・貯める期間ごとの毎月の積立額
2. 金利別の月返済額・総返済額・返済負担率
3. 年収から逆算した借入上限
4. 変動金利が上がっていく場合の試算と、全期間固定との比較
5. 購入後の毎月の住居費と、今の家賃との比較

数値は `sim/params.json` を書き換えて調整する（単位は万円）。
