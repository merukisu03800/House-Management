## シミュレーション

### 画面で使う（おすすめ）
`sim/simulator.html` をブラウザで開く。数字を動かすと結果がすぐに変わる。

```bash
explorer.exe "$(wslpath -w sim/simulator.html)"   # WSL から Windows のブラウザで開く
```

- 1ファイルで完結している（ビルド不要）。編集したらブラウザを再読み込みするだけ
- 計算式は `sim/loan_simulator.py` と同じ。式を変えるときは両方を直す
- 初期値はファイル内の `GROUPS` の `value`（`sim/params.py` と合わせている）
- フォントは Google Fonts から読み込む。オフラインでも、標準のフォントに切り替わって動く
- 参考: 同じ内容を Claude のアーティファクトにも公開している（https://claude.ai/artifact/FxDhcXVkJgAcoNMeZ5Ujfb ）。ローカルを編集しても自動では更新されない

### コマンドで使う

```bash
python3 sim/loan_simulator.py                # sim/params.py の設定で試算
python3 sim/loan_simulator.py --price 5500   # 物件価格(万円)だけ変えて試算
python3 sim/loan_simulator.py --down 0.2     # 頭金を価格の20%にして試算
python3 sim/loan_simulator.py --savings 300  # 今の貯金(万円)を差し引いて積立額を逆算
```

出力される内容:
1. 購入時に必要な現金（頭金＋諸費用）と、頭金の比率・貯める期間ごとの毎月の積立額
2. 金利別の月返済額・総返済額・返済負担率
3. 年収から逆算した借入上限
4. 変動金利が上がっていく場合の試算と、全期間固定との比較
5. 購入後の毎月の住居費と、今の家賃との比較

数値は `sim/params.py` を書き換えて調整する（単位は万円。各項目の意味はファイル内のコメントを参照）。

## 運用ルール

- 決まったことは各メモの「決定事項」に書き、README の「状態」を更新する
- 数字には調べた日付と出典を添える（金利や相場はすぐ変わるため）
- 半年に1回（4月・10月）、金利・相場・制度の情報を見直す
