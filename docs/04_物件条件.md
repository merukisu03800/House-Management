# 04 物件条件

最終更新: 2026-10-01

## 今の希望
- 駅近のマンション、2LDK〜3LDK
- 新築・中古どちらでもよい。ただし築古すぎて汚いものは除外
- 優先順位: 駅からの近さ ＞ 広さ ＝ キレイさ

## 新築と中古の比較
| | 新築 | 中古 |
|---|---|---|
| 価格 | 高い（本八幡駅近くは6,700万円〜） | 新築より安い |
| キレイさ | ◎ | 築年数・リフォームの有無による |
| 実物を見られるか | 完成前に契約することが多い | 実物と管理状態を見て決められる |
| 住宅ローン控除 | 省エネ性能によって変わる | 2026年の改正で優遇が広がった |
| 諸費用 | 3〜5% | 6〜8%（仲介手数料がかかる） |

## 築年数の考え方（「汚い」を避けるために）
- キレイさは、築年数より **リフォームされているか** と **共用部分の管理状態** で決まることが多い
- 「築20年以内」のように線を引くか、「築25年＋リフォーム済み」も対象にするかを決める
- 1981年6月より前に建築確認を受けた物件（旧耐震）は除外する

## 中古で確認すること
- [ ] 管理状態: エントランス、ゴミ置き場、掲示板、自転車置き場
- [ ] 長期修繕計画があるか。修繕積立金は足りているか（**大幅な値上げの予定がないか**）
- [ ] 大規模修繕の実施歴と、次に予定されている時期
- [ ] 管理会社に任せているか（管理組合が自分たちで管理しているか）
- [ ] 総戸数（戸数が少ないと、1戸あたりの修繕費の負担が大きくなりやすい）
- [ ] 住宅ローン控除の要件（新耐震かどうか、省エネ性能の証明書があるか）
- [ ] 必要ならインスペクション（建物状況調査）を依頼する

## 広さの目安
- 3人家族: 2LDKなら55〜65㎡、3LDKなら65〜75㎡くらい
- 住宅ローン控除は床面積40㎡以上が条件（2026年の改正）
- 2人目の子どもの可能性があるため、**3LDK・65㎡以上を基本** にする（2026-10 決定）

- [x] 築20年以内（2028年に買うなら2008年以降に完成した物件）
- [ ] 最低の広さ（㎡）と間取り
- [ ] 譲れない条件と、妥協してよい条件
