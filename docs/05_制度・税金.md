# 05 制度・税金

最終更新: 2026-10-01
※制度は毎年の税制改正で変わる。購入前に必ず最新の内容を確認する。

## 住宅ローン控除（2026年の改正後）
- 2030年12月31日に入居する分まで、5年間延長された
- 年末のローン残高の0.7%が、所得税・住民税から差し引かれる
- 子育て世帯などは、最大控除額が210万円から273万円に増えた
- 床面積の条件は、中古も含めて40㎡以上に緩和された
- 中古住宅の優遇が広がった: 控除期間が10年から13年に延び、借入限度額は最大4,500万円になった
- **省エネ性能によって借入限度額が変わる**（長期優良住宅・ZEH水準・省エネ基準適合・その他）
- [ ] 購入時に子育て世帯の条件に当てはまるか確認する
- [ ] 物件の省エネ性能を示す書類（BELSなど）があるか確認する
- [ ] ペアローンにした場合、2人とも控除を受けられるか

## 住宅取得資金の贈与の非課税枠
- 親などから住宅を買うための資金をもらう場合に、一定額まで贈与税がかからない（省エネ住宅のほうが枠が大きい）
- [ ] 援助の見込みがあれば、制度の期限と金額を確認する

## 購入時・保有中にかかる税金
- 購入時: 登録免許税、不動産取得税、印紙税（軽減措置あり）
- 毎年: 固定資産税・都市計画税（新築には減額措置あり）
