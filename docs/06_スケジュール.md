# 06 スケジュール

最終更新: 2026-10-01
**購入（引き渡し・入居）は 2027年7月**（2026-10-01 に、2〜3年後から変更）。残りは約9ヶ月。

中古マンションは、申し込みから引き渡しまでおよそ2〜3ヶ月かかる。2027年7月に引き渡しを受けるなら、**2027年4〜5月には物件を決めて契約する** 必要がある。

## 2026年10月〜12月: 準備と相場の確認
- [ ] 予算の上限と頭金を決める（[01](01_資金計画.md)）。条件を緩める方向性も決める（[08](08_相場調査.md)）
- [ ] 毎月の積立額を決めて、貯金を始める
- [ ] 信用情報に問題が出ないように、支払いの遅れをなくす（[02](02_住宅ローン.md)）
- [ ] SUUMO・HOME'Sで条件に合う物件を毎週見る。新着の通知を設定する
- [ ] 本八幡と下総中山の周辺を歩く（休日に何度か）

## 2027年1月〜3月: 内覧と銀行への相談
- [ ] 中古物件の内覧を始める（[07](07_物件見学ログ.md) に記録する）
- [ ] 不動産会社を決める
- [ ] **銀行とフラット35に、勤続1年未満（2026年7月入社）でも申し込めるか相談する**（[02](02_住宅ローン.md)）。難しければ、引き渡しを2027年8〜9月にずらす
- [ ] 銀行の事前審査を受けて、借りられる額を確認する
- [ ] 賃貸の契約を確認する（更新時期、退去予告の期限）

## 2027年4月〜5月: 物件を決める
- [ ] 申し込み → 売買契約（手付金として物件価格の5〜10%を現金で払うことが多い）
- [ ] 住宅ローンの本審査

## 2027年6月〜7月: 引き渡し・入居
- [ ] 賃貸の退去予告（多くは1〜2ヶ月前）
- [ ] 残りの代金を払う（ローン実行）→ 引き渡し → 引っ越し
- [ ] 2028年2〜3月に確定申告をする（住宅ローン控除の初年度）

## 見直し
- 毎月: 積立額が計画どおりか確認する
- 金利、本八幡の相場、税制改正の内容を確認する
