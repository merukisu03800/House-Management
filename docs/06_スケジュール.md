# 06 スケジュール

最終更新: 2026-10-01
購入（引き渡し）は 2028〜2029年頃を想定。

## 2026年10月〜2027年3月: 準備
- [ ] 貯金額・毎月の貯金額を把握して、`sim/params.json` に入力する
- [ ] 予算の上限と、頭金の目標額を決める（[01](01_資金計画.md)）
- [ ] 信用情報に問題が出ないように、支払いの遅れをなくす（[02](02_住宅ローン.md)）
- [ ] 本八幡周辺を歩く（休日に何度か）

## 2027年4月〜2027年12月: 情報収集
- [ ] SUUMO・HOME'Sで、条件に合う物件を定期的に見て相場をつかむ（気になったものは [07](07_物件見学ログ.md) に記録する）
- [ ] 新築のモデルルームや、中古物件の内覧に何件か行ってみる（相場観をつけるため）
- [ ] 出産・育休の時期と、ローン審査の時期の関係を整理する
- [ ] 北口の再開発の進み具合を確認する

## 2028年: 本格的な物件探し
- [ ] 銀行の事前審査を受けて、借りられる額を確認する
- [ ] 不動産会社を決める（中古の場合）
- [ ] 物件を決めて申し込み → 契約 → 住宅ローンの本審査

## 引き渡し・入居
- [ ] 賃貸の退去予告（多くは1〜2ヶ月前）
- [ ] 入居した翌年に確定申告をする（住宅ローン控除の初年度）

## 半年ごとの見直し（4月・10月）
- 金利、本八幡の相場、税制改正の内容を確認する
- `docs/01_資金計画.md` の試算を更新する
