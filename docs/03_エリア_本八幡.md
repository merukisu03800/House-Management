# 03 エリア（本八幡・八幡・下総中山）

最終更新: 2026-10-01

## 基本情報
- 本八幡駅: JR総武線（各駅停車）と都営新宿線の本八幡駅、京成本線の京成八幡駅が近くにある
- 市川市。都心への通勤が便利なエリア

## 候補エリア（2026-10-01 決定）
- 第1候補: 本八幡（JR総武線・都営新宿線・京成八幡）
- 第2候補: **下総中山**（本八幡の隣の駅。JR総武線各駅停車のみ）。本八幡で条件に合う物件が予算内にないため、候補に加えた
- [ ] 下総中山から通勤先までの時間を確認する（都営新宿線が使えない）
- [ ] 下総中山の街の様子を歩いて確認する（買い物、保育園、ハザードマップ）
- 下総中山駅の周りは、市川市と船橋市の境目。物件によって市が違うので、保育園や子育ての制度は物件ごとに確認する

## 再開発
- 本八幡駅の北口で再開発（本八幡駅北口駅前地区第一種市街地再開発事業）が進んでいる。地上44階建てのタワーマンションと、商業・業務・公共施設の複合開発
- 新しいタワーマンションが販売されると、周辺の中古マンションの価格や、売り出される物件の数に影響が出る可能性がある
- [ ] 完成・販売の時期を確認する（購入時期と重なるか）

## 確認すること
- [x] 駅からの距離の基準 → 徒歩10分以内
- [ ] 北口と南口の違い（街の雰囲気、買い物のしやすさ）
- [ ] 災害リスク: 市川市のハザードマップで洪水・内水氾濫・液状化を確認する（江戸川に近いエリアは特に注意）
- [ ] 保育園の入りやすさ（市川市の待機児童の状況）
- [ ] 小学校の学区
- [ ] 平日・休日、昼・夜に実際に歩いてみる
- [ ] 比較のための候補エリア（市川、西船橋、船橋など）も持つか
