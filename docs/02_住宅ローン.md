# 02 住宅ローン

最終更新: 2026-10-01

## 金利の状況（2026年9月時点）
- 日銀の利上げを受けて、変動金利は段階的に上がっている（2026年春は0.9〜1.1%台が中心）
- 長期金利が上がっているため、10年固定・35年固定も引き上げが続いている。フラット35（買取型）は3.46%
- 「急激には上げず、段階的に金利を正常化させる」という見方が多い

## 変動か固定か
| | 変動 | 固定 |
|---|---|---|
| 今の金利 | 低い | 高い |
| 金利が上がったとき | 返済額が増える | 増えない |
| 向いている人 | 家計に余裕があり、繰上返済できる | 返済額を確定させたい |

- `sim/loan_simulator.py` の [4] で、変動金利が上がる場合と全期間固定の総返済額を比べられる
- 初期の設定（1.0%から3年ごとに+0.25%、上限3.0%、30年）では、変動の総返済額は約6,930万円、全期間固定2.0%は約7,190万円 → **どこまで金利が上がるか**で結果が変わる

## 借り方
- 方針: **本人の単独ローン**（2026-10 時点）
- 注意: 単独ローンでは、審査も返済負担率も **本人の年収だけ** で見られる。6,000万円の物件で5,400万円を借りる場合、本人の年収が低いと審査に通らなかったり、負担率が高くなったりする
- 本人の年収は900万円で、試算の基準（`income_after_child_man`）と同じ
- 審査の目安: 多くの銀行は返済負担率35%以内、審査用の金利3〜4%で計算する。年収900万円・30年だと、借りられる上限は **約5,500〜6,200万円** → 5,400万円は審査上ぎりぎり届く見込み（銀行によっては減額される可能性あり）
- ただし「審査に通る額」と「無理なく返せる額」は別。返済負担率20%（借入上限は金利1%で約5,300万円、2%で約4,500万円）を目安にして余裕を残す
- **単独ローン**: 夫の収入だけで審査する。家計に余裕を持たせやすい
- **ペアローン**: 夫・妻がそれぞれ借りる。2人とも住宅ローン控除を受けられるが、妻が育休・時短のときも返済は続く
- **収入合算**: 2人の収入を合算して1本のローンを組む
- 育休中は審査で収入が低く見られたり、不利になったりすることがある → **借り入れの審査を受ける時期と、出産・育休の時期の関係** を確認する

## 審査に向けて今から気をつけること
- 転職は勤続年数が短くなるため審査に影響しやすい。購入前の転職は慎重に判断する
  - 本人は2026-10時点で今の会社に入って半年未満。**2027年7月に購入する場合、事前審査（2027年3〜4月頃）の時点で勤続1年前後になる → 審査の一番のリスク**
  - 2026年分の源泉徴収票は、今の会社で働いた期間の分しか載らない。1年分に満たない場合は、給与明細から見込みの年収で審査されることが多い
  - 入社は **2026年7月**。勤続1年になるのは2027年7月
    - 2027年3〜4月の事前審査では勤続8〜9ヶ月、4〜5月の本審査でも10ヶ月前後で、**1年に届かない**
    - 2026年分の源泉徴収票は7〜12月の半年分だけになる
  - 対策の候補:
    1. 勤続1年未満でも申し込める銀行・フラット35に、1〜2月の時点で相談しておく
    2. 引き渡しを2027年8〜9月にずらし、勤続1年を超えてから本審査を受ける
  - [ ] 勤続1年未満でも申し込める銀行・フラット35を候補に入れる
  - 6割以上の金融機関が「勤続1年以上」を求めている。大手銀行は長めの勤続を好む傾向がある
  - 1年未満だと、給与明細から見込みの年収を計算して審査されるため、希望額が通らないことがある
  - フラット35は勤続年数の条件がない
  - **購入までに、もう一度転職しないことが一番の対策**
  - 前の年の源泉徴収票（1年分）が出せる時期に申し込むと、年収をそのまま見てもらいやすい
- クレジットカード・スマホ代の分割払い・奨学金の **支払いを遅らせない**（信用情報に残る）
- 車のローンなど、新しい借り入れを増やさない
- リボ払い・カードローンは使わない
